Privacy policy.

Last updated November 2026. Short version: this is a personal, static site. It doesn't run a backend, doesn't use analytics, and doesn't sell or share data — because there's essentially no data to sell or share.

What this site is

psvineet.me is a single static HTML page hosted on GitHub Pages. There's no server-side code, no database, no user accounts, and no forms that submit anywhere. Everything you see — including the "ask" box on the homepage — runs entirely in your browser with a small built-in set of facts; it isn't a live AI model and it doesn't send what you type anywhere.

What is collected

Nothing is collected by this site itself. There's no first-party or third-party analytics script, no advertising, and no cookies set by psvineet.me.

GitHub Pages, which hosts the site, and any CDN in front of it may log standard web-server data (IP address, user agent, requested URL) the way virtually every web host does. That's outside this site's control — it's Pages infrastructure, not something built into the page.

The status panel (ⓘ)

The small ⓘ button in the corner opens a "site status" panel showing things like the latest deploy and an approximate visitor location. It only does anything when you click it — nothing loads in the background.

When opened, it makes two outbound requests, both visible in the page's Content-Security-Policy:

  • api.github.com — reads public repository metadata (e.g. latest commit) to show deploy status. No authentication, no write access, nothing sent about you.
  • api.ip.sb — a public IP lookup service used to show your approximate location (city-level) and IP in the panel, purely as a visual "where you're connecting from" detail. This request happens directly from your browser to that service; psvineet.me never sees or stores the result.

Neither request happens unless you open the panel, and nothing from either call is stored, logged, or sent anywhere else by this site.

Local storage

The site remembers your light/dark theme choice using your browser's localStorage. That stays on your device — it's never transmitted anywhere and can be cleared any time by clearing site data for psvineet.me.

Cookies

This site does not set any cookies.

Links to other sites

Links out — GitHub, LinkedIn, TryHackMe, the CTF blog, and project repos — go to third-party sites with their own privacy practices. An interstitial notice appears before you leave, but what happens after that is between you and the destination site.

Children's privacy

This is a personal portfolio site, not a service directed at children, and it doesn't knowingly collect information from anyone.

Changes to this policy

If anything here changes — say, a new feature is added that talks to a different third party — this page will be updated and the "last updated" date above will move.

Questions

For anything about this policy, the easiest way to reach out is through GitHub, or by email at ci.vps@proton.me.
